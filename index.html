Learning Notes

Deep-dive notes on the things I'm learning while building real products. Each chapter explains a topic from the ground up: what it is, how it works, what can go wrong, and how to handle it properly. Plain language first, technical detail only where it helps.

Chapters

Chapter 1 · 11 lessons Payment Gateway Integration How online payments work, one-time vs recurring payments, the end-to-end flow, idempotency, creating orders safely at scale, verifying payments, webhooks, renewals and cancellations, one-time add-ons and coupons, and interview Q&A. Chapter 2 · 13 lessons Document Vault (RAG) How uploaded PDFs become chat-ready: the Flask backend for Node developers, uploads and quotas, the cron worker and its lock, text extraction, chunking, embeddings, ChromaDB, and every gap found along the way. Chapter 3 · 63 lessons RAG Bootcamp Notes from the Ultimate RAG Bootcamp course (LangChain, LangGraph, LangSmith), written section by section.

How to read these notes

  • Lessons build on each other. Inside a chapter, read them in order the first time.
  • Coloured boxes have a meaning: green = tip, amber = watch out, red = edge case that breaks things, blue = background context.
  • Examples use Indian payments (UPI, eNACH, RBI rules) and Cashfree's API names, but the ideas apply to any gateway: Razorpay, Stripe, PayU, and others.
