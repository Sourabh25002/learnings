Section 5 · Lesson 23

RAG with ChromaDB, Part 1: Load, Split, Embed

Everything so far comes together in one full RAG pipeline with ChromaDB as the vector store. This part sets up the first steps: data, loading, splitting and the embedding model.

The eight steps

  1. LoadRead documents from their sources.
  2. SplitBreak them into chunks.
  3. EmbedTurn each chunk into a vector.
  4. StoreSave the vectors in ChromaDB.
  5. Process the queryEmbed the user's question.
  6. SearchFind the most similar chunks (nearest-neighbour search, cosine similarity).
  7. AugmentPut the chunks into the prompt with the question.
  8. GenerateThe LLM writes the answer.

This lesson covers steps 1–3; Part 2 stores and searches; Part 3 generates.

ChromaDB

"The open-source search and retrieval database for AI applications": embeddings, vector search, document storage, full-text search, metadata filtering and multimodal retrieval. It can run in the cloud, but here it runs locally, so it acts as a vector store. The course later also uses FAISS. 

import os
from dotenv import load_dotenv
load_dotenv()

# LangChain imports
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.document_loaders import TextLoader, DirectoryLoader
from langchain_openai import OpenAIEmbeddings
from langchain.schema import Document

# Vector store
from langchain_community.vectorstores import Chroma

# Utility imports
import numpy as np
from typing import List

LangChain builds the pipeline, Chroma stores the vectors (needs the chromadb package), and OpenAI provides embeddings and the LLM (Hugging Face embeddings or a Groq LLM work too).

1. Sample data

sample_docs = [
    """Machine Learning Fundamentals
    Machine learning is a subset of artificial intelligence ...""",
    """Deep Learning and Neural Networks
    ...""",
    """Natural Language Processing
    ...""",
]

Three short texts (machine learning, deep learning, NLP), standing in for the pages of a PDF, saved as .txt files so the pipeline starts from real files:

import tempfile

temp_dir = tempfile.mkdtemp()      # a new, empty temporary folder

for i, doc in enumerate(sample_docs):
    with open(f"{temp_dir}/doc_{i}.txt", "w") as f:
        f.write(doc)

print(f"Sample documents created in: {temp_dir}")

2. Load

loader = DirectoryLoader(
    "data",
    glob="*.txt",
    loader_cls=TextLoader,
    loader_kwargs={"encoding": "utf-8"},
)
documents = loader.load()

print(f"Loaded {len(documents)} documents")              # 3
print(documents[0].page_content[:200])                    # "Machine Learning Fundamentals ..."

DirectoryLoader from Lesson 9: 3 Documents.

3. Split

text_splitter = RecursiveCharacterTextSplitter(
    separators=["\n\n", "\n", ". ", " ", ""],
    chunk_size=500,
    chunk_overlap=50,
    length_function=len,
)
chunks = text_splitter.split_documents(documents)

print(f"Created {len(chunks)} chunks from {len(documents)} documents")   # 5 from 3
print(chunks[0].page_content)
print(chunks[0].metadata)

With chunk size 500 and overlap 50, the 3 documents become 5 chunks, each keeping its source in metadata.

The embedding model

os.environ["OPENAI_API_KEY"] = os.getenv("OPENAI_API_KEY")

embeddings = OpenAIEmbeddings()     # no model given → the default model

sample_text = "..."                 # any test sentence
vector = embeddings.embed_query(sample_text)
print(vector)                        # the full vector for sample_text

With no model given, OpenAIEmbeddings uses its default (text-embedding-ada-002 in the video). This only embeds a test sentence; Part 2 embeds all the chunks while storing them.

Takeaways

  • A full RAG pipeline: load, split, embed, store, process the query, search, augment, generate.
  • ChromaDB, run locally, is the vector store here.
  • 3 documents → 5 chunks, ready to embed and store.
