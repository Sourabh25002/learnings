Section 5 · Lesson 31

RAG with FAISS, Part 2: Three RAG Chains

Three common chain types on the FAISS store, built with LCEL and a Groq LLM: simple (basic Q&A), conversational (with chat history) and streaming (the answer arrives piece by piece).

LLM, prompt, retriever

from langchain.chat_models import init_chat_model

os.environ["GROQ_API_KEY"] = os.getenv("GROQ_API_KEY")
llm = init_chat_model("groq:gemma2-9b-it")     # a ChatGroq model
simple_prompt = ChatPromptTemplate.from_template("""Answer the question based on the following context:

Context: {context}

Question: {question}

Answer:""")
retriever = vectorstore.as_retriever(
    search_type="similarity",
    search_kwargs={"k": 3},
)

search_type="similarity" is plain similarity search, top 3 chunks.

Formatting with sources

from typing import List

def format_docs(docs: List[Document]) -> str:
    """Format documents for insertion into the prompt"""
    formatted = []
    for i, doc in enumerate(docs):
        source = doc.metadata.get("source", "Unknown")
        formatted.append(f"Document {i + 1} (Source: {source}):\n{doc.page_content}")
    return "\n\n".join(formatted)

Unlike Lesson 26's version, each chunk is numbered and labelled with its source, so the LLM can tell them apart and cite them.

1. Simple chain

simple_rag_chain = (
    {
        "context": retriever | format_docs,
        "question": RunnablePassthrough(),
    }
    | simple_prompt
    | llm
    | StrOutputParser()
)

The LCEL chain from Lesson 26.

2. Conversational chain

conversational_prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant. Use the provided context to answer the question."),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "Context: {context}\n\nQuestion: {input}"),
])
conversational_rag = (
    RunnablePassthrough.assign(
        context=lambda x: format_docs(retriever.invoke(x["input"]))
    )
    | conversational_prompt
    | llm
    | StrOutputParser()
)

The input is a dictionary with input and chat_history; RunnablePassthrough.assign passes it on and adds a context key with the retrieved chunks.

Compared with Lesson 28

Here the search uses the question as typed; only the LLM sees the history. Lesson 28's history-aware retriever rewrites the question first, so vague follow-ups still retrieve the right chunks.

3. Streaming chain

streaming_rag_chain = (
    {
        "context": retriever | format_docs,
        "question": RunnablePassthrough(),
    }
    | simple_prompt
    | llm               # no StrOutputParser
)

The simple chain without the output parser, used with .stream(): streaming sends the answer in pieces as the LLM generates it, so users see it start immediately.

ChainCall withReturns
Simple.invoke("question")Answer string
Conversational.invoke({"input": ..., "chat_history": [...]})Answer string
Streaming.stream("question")Pieces (print chunk.content)

Testing

def test_rag_chains(question):
    print(f"Question: {question}")

    # 1. Simple RAG chain
    answer = simple_rag_chain.invoke(question)
    print(f"Simple RAG answer: {answer}")

    # 2. Streaming RAG chain
    print("Streaming RAG answer: ", end="")
    for chunk in streaming_rag_chain.stream(question):
        print(chunk.content, end="", flush=True)
    print()

test_rag_chains("What is the difference between AI and machine learning?")
# "AI is the broad concept of machines simulating human intelligence ..."
test_questions = [
    "What is the difference between AI and machine learning?",
    "Explain deep learning in simple terms",
    # ... a question about NLP
]
for q in test_questions:
    test_rag_chains(q)

"AI is the broad concept of machines simulating human intelligence…": both chains give the same answer, displayed differently. (A "model does not exist" error usually means a typo in the model name.)

chat_history = []

q1 = "What is machine learning?"
a1 = conversational_rag.invoke({"input": q1, "chat_history": chat_history})
print(a1)   # "Machine learning is a subset of artificial intelligence ..."

# Update the history
chat_history.extend([
    HumanMessage(content=q1),
    AIMessage(content=a1),
])

q2 = "How is it different from traditional programming?"
a2 = conversational_rag.invoke({"input": q2, "chat_history": chat_history})
print(a2)   # traditional programming = explicit, step-by-step instructions; machine learning = ...

The follow-up "How is it different from traditional programming?" is answered about machine learning, thanks to the history.

OpenAI LLMs are more accurate but paid; Groq's open models are free but may be less accurate.

Takeaways

  • Once a store is a retriever, FAISS and Chroma plug into chains the same way.
  • Three chains: simple, conversational (RunnablePassthrough.assign), streaming (no parser, .stream()).
  • Labelling chunks with sources helps the LLM cite them.
