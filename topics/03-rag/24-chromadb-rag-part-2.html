Section 5 · Lesson 24

RAG with ChromaDB, Part 2: Store and Search

The 5 chunks from Part 1 are embedded and stored in Chroma, then searched for the chunks most relevant to a question.

Creating the vector store

# Create the vector store
persist_directory = "./chroma_db"

# Initialize ChromaDB with OpenAI embeddings
vectorstore = Chroma.from_documents(
    documents=chunks,
    embedding=embeddings,
    persist_directory=persist_directory,
    collection_name="rag_collection",
)

print(f"Vector store created with {vectorstore._collection.count()} vectors")
print(f"Persisted to: {persist_directory}")
ParameterMeaning
documentsThe chunks to store.
embeddingThe model that turns each chunk into a vector.
persist_directoryThe folder where Chroma saves everything, so it survives restarts.
collection_nameA name for this set of vectors (like a table name).

from_documents embeds every chunk and stores the vector together with its text and metadata: "Vector store created with 5 vectors". A chroma_db folder appears holding Chroma's database files.

Similarity search

A vector store has search built in, so there's no need for the hand-written function of Lesson 21:

query = "What are the types of machine learning?"

similar_docs = vectorstore.similarity_search(query, k=3)

print(f"Query: {query}")
print(f"Top {len(similar_docs)} similar chunks:")
for i, doc in enumerate(similar_docs):
    print(f"\n--- Chunk {i + 1} ---")
    print(doc.page_content)
    print(f"Metadata: {doc.metadata}")

k=3 returns the 3 closest chunks, each a Document with its text and metadata.

Query1st result2nd result
What are the types of machine learning?Machine Learning FundamentalsDeep Learning and Neural Networks
What is NLP?Natural Language ProcessingDeep learning (RNNs, transformers)
What is deep learning?Deep Learning and Neural NetworksMachine Learning Fundamentals

You give the store text and get text back: it embeds the query with the same model it used for the chunks, compares, and returns the matching chunks.

Scores: lower is better here

results_scores = vectorstore.similarity_search_with_score(query, k=3)

for doc, score in results_scores:
    print(f"Score: {score:.3f}")
    print(doc.page_content[:100])

For "What is deep learning?" the best chunk scores about 0.23 and the third about 0.397. The best match has the lowest score because Chroma's default score is L2 (Euclidean) distance: how far apart two vectors are (0 = identical, typically up to about 2).

Distance vs similarity

A distance (Chroma) is lower = more similar; cosine similarity (Lessons 18–21) is higher = more similar. Always check which one a store returns.

Other methods: similarity_search_by_vector (search with a vector instead of text), …_with_relevance_scores, and image search. The two above cover most needs.

These chunks are only the store's output, not an answer yet. Part 3 hands them to an LLM.

Takeaways

  • Chroma.from_documents(...) embeds and saves all chunks in one call.
  • similarity_search(query, k) returns the top k chunks as Documents.
  • Chroma's scores are distances: lower = more similar.
