Section 4 · Lesson 20

OpenAI Embeddings

The same job with OpenAI's paid, more accurate embedding models. The code barely changes; what's new is the API key.

The models

OpenAI's embedding models are text-embedding-3-small, text-embedding-3-large and the older text-embedding-ada-002. They're priced per 1 million tokens; 3-large costs much more because it's a bigger model.

API key

You need an OpenAI account with some credit (about $5 is plenty for practice) and an API key (a secret that identifies your account, starting with sk-). Keep it in a .env file, not in the code: 

# .env
OPENAI_API_KEY="sk-..."
import os
from dotenv import load_dotenv

load_dotenv()                     # reads .env; returns True
os.getenv("OPENAI_API_KEY")       # check the key was loaded

os.environ["OPENAI_API_KEY"] = os.getenv("OPENAI_API_KEY")

Without the key set, creating the model fails with "The api_key client option must be set…".

Loading and using the model

from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
single_text = "LangChain and RAG are amazing frameworks and projects to work on"
single_embedding = embeddings.embed_query(single_text)

print(f"Text: {single_text}")
print(f"Dimensions: {len(single_embedding)}")   # 1536
print(single_embedding[:5])                      # just the first 5 numbers

One sentence → a vector of 1,536 numbers (4× the Hugging Face model's 384).

multiple_texts = [
    "Python is a programming language",
    "LangChain is a framework for LLM applications",
    "Embeddings convert text to numbers",
    "Vectors can be compared for similarity",
]

multiple_embeddings = embeddings.embed_documents(multiple_texts)

print(f"Number of texts: {len(multiple_texts)}")              # 4
print(f"Number of embeddings: {len(multiple_embeddings)}")    # 4
print(f"Each embedding size: {len(multiple_embeddings[0])}")  # 1536

Four texts → four vectors of 1,536 dimensions each. embed_query and embed_documents work exactly as in Lesson 19.

Hugging Face vs OpenAI, and which OpenAI model

Hugging Face

  • Free, open source
  • No API key
  • 384 dimensions (MiniLM)

OpenAI

  • Paid per token, more accurate
  • Needs a key and credits
  • 1,536 dimensions (3-small)
ModelDimensionsCost / 1M tokensUse when
text-embedding-3-small1,536$0.02General purpose, cost-effective
text-embedding-3-large3,072$0.13Accuracy is critical
text-embedding-ada-002——Legacy only; avoid for new work

Takeaways

  • OpenAI embeddings: paid, more accurate; need a key (kept in .env) and credits.
  • OpenAIEmbeddings(model=...) has the same methods as the Hugging Face class.
  • 3-small for most work; 3-large when accuracy matters most.
