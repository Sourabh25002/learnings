Section 11 · Lesson 60

Structured Output with TypedDict

A lighter schema from Python's built-in typing: TypedDict. It describes the shape but doesn't validate, and the result is a plain dictionary. 

from typing_extensions import TypedDict, Annotated

class MovieDict(TypedDict):
    """A movie with details."""
    title: Annotated[str, ..., "The title of the movie"]
    year: Annotated[int, ..., "The year the movie was released"]
    director: Annotated[str, ..., "The director of the movie"]
    rating: Annotated[float, ..., "The movie's rating out of 10"]

model_with_typeddict = model.with_structured_output(MovieDict)

response = model_with_typeddict.invoke("Provide details about the movie Avengers")
response
# {'title': 'The Avengers', 'year': 2012, 'director': 'Joss Whedon', 'rating': ...}

Annotated[type, ..., "description"] gives each field a type and description (... means required). The Avengers come back as a dictionary: Joss Whedon, 2012.

Nesting

class Actor(TypedDict):
    name: str
    role: str

class MovieDetails(TypedDict):
    title: Annotated[str, ..., "The movie title"]
    year: Annotated[int, ..., "The release year"]
    cast: list[Actor]
    genres: list[str]
    budget: Annotated[float | None, None, "Budget in millions USD"]

model_with_typeddict = model.with_structured_output(MovieDetails)
model_with_typeddict.invoke("Provide details about the movie Inception")

Works as with Pydantic, as nested dictionaries and lists.

model.profile

model.profile
# {'max_input_tokens': ..., 'max_output_tokens': ...,
#  'image_inputs': False, 'audio_inputs': False, 'video_inputs': False,
#  'reasoning_output': True, 'tool_calling': True, ...}

What a model supports: token limits, image/audio/video input, reasoning, tool calling (for Qwen3: reasoning and tools yes, images no). Useful before relying on a model for, e.g., multimodal RAG. Check it on the model itself; the structured-output wrapper doesn't have it.

Takeaways

  • TypedDict: shape without validation; returns dicts.
  • model.profile lists a model's capabilities.
