Section 3 · Lesson 9

Loading Text Files

The simplest source: plain .txt files. TextLoader reads one file, DirectoryLoader reads every matching file in a folder. Both return Documents.

The sample data: data/text_files/ with two files, python_intro.txt and machine_learning.txt, standing in for real company documents.

TextLoader: one file

from langchain_community.document_loaders import TextLoader

loader = TextLoader("data/text_files/python_intro.txt", encoding="utf-8")
documents = loader.load()

print(type(documents))
print(documents)
  • encoding="utf-8": read the file with UTF-8, the standard way of storing text as bytes (more).
  • .load() does the actual reading.
<class 'list'>
[Document(metadata={'source': 'data/text_files/python_intro.txt'},
          page_content='Python Programming Introduction\n\nPython is a high-level ...')]

A list with one Document holding the whole file. The loader fills in metadata["source"] with the file's path automatically. 

print(f"Loaded {len(documents)} document")
print(f"Content preview: {documents[0].page_content[:100]}...")
print(f"Metadata: {documents[0].metadata}")

DirectoryLoader: a whole folder

from langchain_community.document_loaders import DirectoryLoader, TextLoader

dir_loader = DirectoryLoader(
    "data/text_files",
    glob="**/*.txt",
    loader_cls=TextLoader,
    loader_kwargs={"encoding": "utf-8"},
    show_progress=True,
)
documents = dir_loader.load()
ParameterMeaning
pathThe folder to read.
globWhich files to pick, as a pattern: **/*.txt = every .txt file in the folder and its sub-folders.
loader_clsThe loader used for each file found (here TextLoader).
loader_kwargsSettings passed to that loader for every file (here UTF-8).
show_progressShows a progress bar.
 
print(f"Loaded {len(documents)} documents")
for i, doc in enumerate(documents):
    print(f"\nDocument {i + 1}:")
    print(f"  Source: {doc.metadata['source']}")
    print(f"  Length: {len(doc.page_content)} characters")
Loaded 2 documents

Document 1:
  Source: data/text_files/machine_learning.txt
  Length: ... characters

Document 2:
  Source: data/text_files/python_intro.txt
  Length: ... characters

One Document per file, each with its own source.

Advantages

  • Many files at once
  • Glob patterns, including sub-folders
  • Progress tracking

Disadvantages

  • All files must be the same type (one loader for all)
  • Limited error handling per file
  • Slow and memory-hungry on huge folders

Takeaways

  • TextLoader: one file → a list with one Document.
  • DirectoryLoader: a folder → one Document per matching file, using the loader you choose.
  • Metadata gets source automatically.
