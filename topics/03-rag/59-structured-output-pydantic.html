Section 11 · Lesson 59

Structured Output with Pydantic

Structured output makes the model answer in a format you define (e.g. a movie as title, year, director, rating), so code can use the result directly. Schemas can be Pydantic models (here), TypedDicts or dataclasses (next lessons).

Defining the schema

import os
from langchain.chat_models import init_chat_model

os.environ["GROQ_API_KEY"] = os.getenv("GROQ_API_KEY")
model = init_chat_model("groq:qwen/qwen3-32b")     # a reasoning model

from pydantic import BaseModel, Field

class Movie(BaseModel):
    title: str = Field(description="The title of the movie")
    year: int = Field(description="The year the movie was released")
    director: str = Field(description="The director of the movie")
    rating: float = Field(description="The movie's rating out of 10")

A Pydantic model: each field has a type and a Field(description=...) that tells the LLM what goes there.

Using it

model_with_structure = model.with_structured_output(Movie)

response = model_with_structure.invoke("Provide details about the movie Inception")
response
# Movie(title='Inception', year=2010, director='Christopher Nolan', rating=8.8)

Instead of free text, the response is a Movie object: Inception, 2010, Christopher Nolan, 8.8. Under the hood the schema is offered to the model like a tool; the model fills in its arguments and a parser builds the object.

Pydantic validates every field: your code gets the types it expects, or an error, never silently bad data.

In RAG this is how you get, say, an answer plus a list of sources as separate fields instead of one blob of text.

include_raw

model_with_structure = model.with_structured_output(Movie, include_raw=True)

response = model_with_structure.invoke("Provide details about the movie Inception")
# {
#   "raw": AIMessage(...),          # the model's original message
#   "parsed": Movie(...),           # the structured result
#   "parsing_error": None,
# }

Returns the model's raw message, the parsed object and any parsing error, useful for debugging.

Nested structures

class Actor(BaseModel):
    name: str
    role: str

class MovieDetails(BaseModel):
    title: str = Field(description="The movie title")
    year: int = Field(description="The release year")
    cast: list[Actor]                      # a list of Actor objects
    genres: list[str]
    budget: float | None = Field(None, description="Budget in millions USD")

model_with_structure = model.with_structured_output(MovieDetails)
response = model_with_structure.invoke("Provide details about the movie Inception")

Models can contain models: cast is a list of Actors (DiCaprio as Dom Cobb, Gordon-Levitt as Arthur…), and budget is optional (160.0, i.e. $160M).

Takeaways

  • model.with_structured_output(Schema) returns schema objects instead of text.
  • Pydantic adds field descriptions, validation and nesting.
