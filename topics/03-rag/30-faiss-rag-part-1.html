RAG with FAISS, Part 1: The Vector Store

The second vector store, FAISS: building it, saving and loading it, and searching with scores and metadata filters. Part 2 builds chains on top.

FAISS

"A library for efficient similarity search and clustering of dense vectors", open source from Facebook (Meta). It compares vectors by L2 distance or dot product, and indexes them (organises them in a structure built for fast nearest-neighbour search). Extremely fast, memory efficient, handles millions of vectors, and can use a GPU. The course uses the CPU version, faiss-cpu: 

from langchain_community.vectorstores import FAISS

Data and chunks

sample_documents = [
    Document(
        page_content="Artificial intelligence ...",
        metadata={"source": "...", "topic": "AI"},
    ),
    Document(
        page_content="Machine learning basics ...",
        metadata={"source": "...", "topic": "ML"},
    ),
    # ... deep learning, NLP
]

text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=50,
    length_function=len,
    separators=[" "],
)
chunks = text_splitter.split_documents(sample_documents)
print(f"{len(chunks)} chunks from {len(sample_documents)} documents")   # 4 from 4

Four Documents (AI, machine learning, deep learning, NLP), each with a source and a topic. They're short, so 4 documents → 4 chunks.

Embeddings

os.environ["OPENAI_API_KEY"] = os.getenv("OPENAI_API_KEY")

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small",
    dimensions=1536,
)

sample_embedding = embeddings.embed_query("What is machine learning?")

texts = ["AI", "Machine learning", "Deep learning", "Neural networks"]
batch_embeddings = embeddings.embed_documents(texts)   # 4 vectors
print(batch_embeddings[0])                              # the vector for "AI"

OpenAI's 3-small (its default 1,536 dimensions written out). A quick similarity check:

def compare_embeddings(text1: str, text2: str) -> float:
    """Compare semantic similarity of two texts using embeddings"""
    embedding1 = np.array(embeddings.embed_query(text1))
    embedding2 = np.array(embeddings.embed_query(text2))
    similarity = np.dot(embedding1, embedding2) / (
        np.linalg.norm(embedding1) * np.linalg.norm(embedding2)
    )
    return similarity

Building the store

vectorstore = FAISS.from_documents(
    documents=chunks,
    embedding=embeddings,
)

print(f"Vector store created with {vectorstore.index.ntotal} vectors")   # 4

Same from_documents pattern as Chroma; index.ntotal is the number of vectors: 4.

Saving and loading

FAISS lives in memory, so save it to keep it:

vectorstore.save_local("faiss_index")
loaded_vectorstore = FAISS.load_local(
    "faiss_index",
    embeddings,
    allow_dangerous_deserialization=True,
)
print(loaded_vectorstore.index.ntotal)   # 4

Load it with the same embedding model used to build it. Part of the saved folder is a pickle file, which can run hidden code when loaded, hence allow_dangerous_deserialization=True: only for files you created.

Searching

query = "What is deep learning?"

results = vectorstore.similarity_search(query, k=3)
for i, doc in enumerate(results):
    print(f"{i + 1}. {doc.metadata}")
    print(doc.page_content)

Top 3: deep learning, then ML basics, then NLP.

results_with_score = vectorstore.similarity_search_with_score(query, k=3)
for doc, score in results_with_score:
    print(f"Score: {score:.3f}  {doc.metadata}")

Best match 0.556, next about 1.208. Like Chroma, these are distances: lower = more similar.

Metadata filtering

filter_dict = {"topic": "ML"}

filtered_results = vectorstore.similarity_search(
    query,
    k=3,
    filter=filter_dict,
)
print(len(filtered_results))   # 1

Only chunks whose metadata matches are searched: just 1 result despite k=3. Filtering narrows the search before ranking, a key reason to add good metadata.

Takeaways

  • FAISS: Meta's fast, in-memory vector index.
  • save_local / load_local to persist it, with the same embedding model.
  • filter={...} searches only chunks with matching metadata.
