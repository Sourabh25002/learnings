Section 8 · Lesson 50

HyDE: Hypothetical Document Embeddings

Instead of searching with the question, HyDE has an LLM write a hypothetical answer first, then searches with that answer's embedding.

Why it works

Documents are written like answers, not like questions. An answer-shaped text lands closer to the right documents in embedding space than a short question does. Use HyDE when queries are short, when queries and documents use different words, or when you want to match on answer content.

The fake answer can be wrong, and that's fine

It may contain made-up details, but it's only used to find documents; the final answer comes from the real ones.

Way 1: by hand

from langchain_community.document_loaders import WikipediaLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter

loader = WikipediaLoader(query="Steve Jobs", load_max_docs=5)
documents = loader.load()

splitter = RecursiveCharacterTextSplitter(chunk_size=300, chunk_overlap=100)
docs = splitter.split_documents(documents)

WikipediaLoader fetches up to 5 Wikipedia articles for a search term (needs the wikipedia package), with title, summary and URL in metadata.

from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.vectorstores import Chroma   # or FAISS

embeddings = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
db = Chroma.from_documents(docs, embedding=embeddings, persist_directory="...")
base_retriever = db.as_retriever(search_kwargs={"k": 5})

llm = init_chat_model("groq:gemma2-9b-it")
from langchain_core.prompts import ChatPromptTemplate, SystemMessagePromptTemplate

def get_hyde_doc(query):
    template = """Imagine you are an expert writing a detailed explanation on the topic: '{query}'.
Your response should be comprehensive and include all key points.
Create a hypothetical answer for the topic."""
    system_message_prompt = SystemMessagePromptTemplate.from_template(template)
    chat_prompt = ChatPromptTemplate.from_messages([system_message_prompt])
    messages = chat_prompt.format_prompt(query=query).to_messages()
    response = llm.invoke(messages)
    return response.content

query = "Why was Steve Jobs fired from Apple?"
hyde_doc = get_hyde_doc(query)
print(hyde_doc)                                   # the hypothetical answer

matched_docs = base_retriever.invoke(hyde_doc)    # search with the answer, not the question

The LLM writes an expert-style answer to "Why was Steve Jobs fired from Apple?", and that text is what the retriever searches with.

Way 2: HypotheticalDocumentEmbedder

from langchain.chains.hyde.base import HypotheticalDocumentEmbedder

base_embeddings = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")

hyde_embedding_function = HypotheticalDocumentEmbedder.from_llm(
    llm=llm,
    base_embeddings=base_embeddings,
    prompt_key="web_search",
)

vectorstore = Chroma.from_documents(
    docs,                                   # chunks from a text dataset about LangChain
    embedding=hyde_embedding_function,
    persist_directory="...",
)
  • LangChain packages HyDE as an embedding function: the LLM writes the hypothetical document, base_embeddings embeds it.
  • prompt_key="web_search" picks a built-in prompt (others: "sci_fact", "fiqa", "trec_news"…).
  • Only queries go through the LLM; documents are embedded normally.
prompt = PromptTemplate.from_template("""Use the context below to answer the question.

Context:
{context}

Question: {input}""")
document_chain = create_stuff_documents_chain(llm, prompt)

def hyde_rag_pipeline(query):
    matched_docs = vectorstore.similarity_search(query)     # HyDE runs inside this search
    response = document_chain.invoke({"context": matched_docs, "input": query})
    return response, matched_docs

response, matched_docs = hyde_rag_pipeline("...")          # a question about LangChain memory
print(response)
# "LangChain provides a memory module called ConversationBufferMemory ..."

similarity_search now runs query → hypothetical answer → embedding → search, then the matches go to the answering chain ("LangChain provides a memory module called ConversationBufferMemory…").

custom_prompt = PromptTemplate.from_template(
    "Generate a concise hypothetical answer for this topic: {query}"
)

hyde_embedding_function = HypotheticalDocumentEmbedder.from_llm(
    llm=llm,
    base_embeddings=base_embeddings,
    custom_prompt=custom_prompt,          # instead of prompt_key
)

Or pass your own prompt as custom_prompt.

Interview points: handles vocabulary mismatch and vague queries, works zero-shot (no training data), plug and play (just swap the embedding function).

Takeaways

  • HyDE: search with an LLM-written answer, because answers look like documents.
  • HypotheticalDocumentEmbedder makes it a drop-in embedding function.
