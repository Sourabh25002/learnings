Section 8 · Lesson 47

Query Expansion

Query enhancement techniques improve the user's question before it reaches the retriever. The first, query expansion, turns a short, vague query into a fuller one.

The quality of the query sent to the retriever decides how good the retrieved context is, and so how accurate the answer will be.

Users often type very little ("LangChain memory"), which gives the retriever little to match against.

What it is

Query expansion rewrites the user's query with synonyms, related terms and context, to retrieve better documents from the knowledge base (the vector store). Use it when the query is short, ambiguous or underspecified, or to catch synonyms and spelling variants.

OriginalExpanded
LangChain memoryLangChain memory modules, conversation memory
Tools in LLMLangChain tools, API calculators, agent tools
RetrievalVector retrieval, dense search, BM25, MMR

The expanded query contains the words relevant documents are likely to use, giving both keyword and semantic search more to match.

Where it fits

One new step before the retriever: a small chain of a prompt ("expand this query with synonyms and context") and an LLM. Everything after it is unchanged.

Takeaways

  • Better query → better chunks → better answer.
  • Query expansion = an LLM rewrites a thin query into a rich one, before retrieval.
