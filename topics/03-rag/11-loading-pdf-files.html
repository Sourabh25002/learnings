Section 3 · Lesson 11

Loading PDF Files

Companies have huge amounts of PDFs, so this is one of the most common RAG sources. Two loaders: PyPDFLoader and PyMuPDFLoader.

The sample is data/pdf/attention.pdf: "Attention Is All You Need" (15 pages), the paper that introduced the Transformer architecture behind today's LLMs. LangChain has three common PDF loaders: 

from langchain_community.document_loaders import (
    PyPDFLoader,
    PyMuPDFLoader,
    UnstructuredPDFLoader,   # covered later in the course
)

PyPDFLoader

try:
    pypdf_loader = PyPDFLoader("data/pdf/attention.pdf")
    pypdf_docs = pypdf_loader.load()

    print(f"Loaded {len(pypdf_docs)} pages")
    print(f"Page 1 content: {pypdf_docs[0].page_content[:100]}...")
    print(f"Metadata: {pypdf_docs[0].metadata}")
except Exception as e:
    print(f"Error: {e}")
Loaded 15 pages
Page 1 content: (first 100 characters of page 1)...
Metadata: {'producer': '...', 'creator': '...', 'creationdate': '...',
           'author': '', 'keywords': '', 'moddate': '...', 'ptex.fullbanner': '...',
           'source': 'data/pdf/attention.pdf', 'total_pages': 15, 'page': 0, ...}
  • One Document per page: 15 pages, 15 Documents.
  • Rich metadata: the PDF's own information (producer, creator, author, dates, total pages) plus the page number. Every chunk made from a page keeps it, so an answer can say exactly which page it came from.

PyMuPDFLoader

pymupdf_loader = PyMuPDFLoader("data/pdf/attention.pdf")
pymupdf_docs = pymupdf_loader.load()

print(f"Loaded {len(pymupdf_docs)} pages")

Same output shape (one Document per page), but faster and better at extraction. Needs the pymupdf package.

Which to use

PyPDFLoaderPyMuPDFLoader
StrengthsSimple, reliable, keeps page numbersFast, good text extraction, can extract images
Weak spotPDFs with images or encoded characters—
Use whenStandard text PDFsSpeed matters; the instructor's recommendation

Takeaways

  • PDF loaders return one Document per page, with the page number in metadata.
  • PyMuPDFLoader is faster and extracts better; PyPDFLoader is the simple default.
