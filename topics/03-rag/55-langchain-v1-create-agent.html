Section 11 · Lesson 55

LangChain v1: Creating Agents

LangChain v1 (version 1.1.0 here) reworked agents, model integrations, tools, structured output, messages, memory, streaming, and added middleware and guardrails. This section covers them, starting with agents.

What makes an app an agent

A plain generative AI app is input → LLM → output, limited to what the LLM learned before its training cut-off. Ask "What's today's AI news?" and an agent recognises it can't know, calls a tool (a web search API, a database…), and answers from the tool's result.

An agent is an LLM that decides by itself when to use a tool, and answers from what the tool returns. (A retriever over a vector store can be such a tool; that's agentic RAG.)

This used to be wired up by hand (ReAct); v1's create_agent does it in one call.

create_agent

import os
from dotenv import load_dotenv
load_dotenv()
os.environ["OPENAI_API_KEY"] = os.getenv("OPENAI_API_KEY")

from langchain.agents import create_agent

agent = create_agent(
    model="gpt-5",
    tools=[],
    system_prompt="You are a helpful assistant",
)
agent

A model (GPT-5), tools (none yet) and a system prompt. Its graph is just start → model → end. (verbose=True isn't supported.)

Adding a tool

def get_weather(city: str) -> str:
    """Get the weather for a city."""
    return f"The weather in {city} is sunny"

agent = create_agent(
    model="gpt-5",
    tools=[get_weather],
    system_prompt="You are a helpful assistant",
)

The model can now loop through the tools before answering. The LLM chooses tools from their name, parameters and docstring ("Get the weather for a city"), so write that clearly.

Running it

response = agent.invoke({
    "messages": [{"role": "user", "content": "What is the weather like in New York?"}]
})

The input must be a dictionary with a "messages" list. The response's messages show the agent's steps:

  1. Human"What is the weather like in New York?"
  2. AI: tool callget_weather(city="New York")
  3. Tool"The weather in New York is sunny"
  4. AI: answer"It's sunny in New York."
print(response["messages"][-1].content)     # just the final answer

# Shorter: a plain string as the messages value is treated as the user's message
agent.invoke({"messages": "What is the weather in New York?"})
import langchain
print(langchain.__version__)    # 1.1.0

Takeaways

  • Agent = LLM + tools it decides to use.
  • create_agent(model, tools, system_prompt); invoke with {"messages": [...]}; the last message is the answer.
