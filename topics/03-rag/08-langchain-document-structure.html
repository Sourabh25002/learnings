Section 3 · Lesson 8

LangChain Document Structure

Whatever the source, LangChain converts the data into one shape: a Document, a container holding a piece of text plus information about it. Chunking, embedding and storing all work on Documents.

The two parts of a Document

FieldTypeHolds
page_contentStringThe text itself: what gets embedded and searched.
metadataDictionaryInformation about the text: source, page, author, date, anything you like. It's stored and retrieved along with the text.

Creating one

from langchain_core.documents import Document
from langchain.text_splitter import (
    RecursiveCharacterTextSplitter,
    CharacterTextSplitter,
    TokenTextSplitter,
)

Besides Document, these imports bring in the three text splitters used in Lesson 10.

doc = Document(
    page_content="This is the main text content that will be embedded and searched.",
    metadata={
        "source": "example.txt",
        "page": 1,
        "author": "Krish",
        "date_created": "2024-01-01",
        "custom_field": "any_value",
    },
)

print(f"Content: {doc.page_content}")
print(f"Metadata: {doc.metadata}")
Content: This is the main text content that will be embedded and searched.
Metadata: {'source': 'example.txt', 'page': 1, 'author': 'Krish', 'date_created': '2024-01-01', 'custom_field': 'any_value'}

The metadata keys (source, page, author, date_created) are examples; metadata is just a dictionary, so add whatever is useful.

Why metadata matters

  • Filtering searches (e.g. only one source or date range)
  • Tracking sources, so answers can cite them
  • Extra context in responses
  • Debugging and auditing

You ask "Who is the author of this?" The text doesn't say, but author: "Krish" is stored with it as metadata, so the system can answer. Metadata is a big part of what makes advanced RAG better than basic RAG.

Loaders return Documents

You'll rarely build Documents by hand. A document loader is a ready-made reader for one file type (PDF, text, Word…) that returns a list of Documents: 

type(doc)
# langchain_core.documents.base.Document

Takeaways

  • Document = page_content (the text) + metadata (a dictionary about it).
  • Metadata enables filtering, citing sources and better answers.
  • Loaders read files and hand back Documents.
