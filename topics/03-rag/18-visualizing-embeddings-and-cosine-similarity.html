Section 4 · Lesson 18

Visualizing Embeddings and Cosine Similarity

The previous lesson in code: plot a few word vectors to see that similar words cluster, then compute cosine similarity to measure it, with NumPy and Matplotlib.

Dimensions

Each number in a vector is a dimension. Real embedding models produce many, and the count depends on the model:

Model (example)Dimensions
An OpenAI embedding modelaround 1,500
A Hugging Face embedding model384

The dimensions have no names: unlike the "action/comedy" example, nobody knows what each number stands for.

Similar words cluster

Made-up 2-dimensional vectors, so they can be plotted:

import numpy as np
import matplotlib.pyplot as plt

word_embeddings = {
    "cat":    [0.8, 0.6],
    "kitten": [0.75, 0.65],
    "dog":    [0.7, 0.3],
    "puppy":  [0.65, 0.35],
    # "car" and "truck": values far from the animals
}

fig, ax = plt.subplots(figsize=(8, 6))
for word, coords in word_embeddings.items():
    ax.scatter(coords[0], coords[1], s=100)      # first number on x, second on y
    ax.annotate(word, (coords[0], coords[1]))     # label the point with its word
plt.show()

Three clusters: cat and kitten, dog and puppy, and car and truck far from the animals.

Cosine similarity in code

cosine similarity = (A · B) / (‖A‖ × ‖B‖)

The formula from Lesson 17, with a NumPy function for each part:

def cosine_similarity(vec1, vec2):
    dot_product = np.dot(vec1, vec2)    # A · B
    norm_a = np.linalg.norm(vec1)       # ‖A‖, magnitude of A
    norm_b = np.linalg.norm(vec2)       # ‖B‖, magnitude of B
    return dot_product / (norm_a * norm_b)

A dot product multiplies the two vectors number by number and adds the results into one number; norm is a vector's length.

Reading the result

Close toMeaning
1Very similar
0Not related
−1Opposite
 
cat_kitten_similarity = cosine_similarity(cat_vector, kitten_vector)
print(cat_kitten_similarity)   # 0.996

cat_car_similarity = cosine_similarity(cat_vector, car_vector)
print(cat_car_similarity)      # -0.4367

Cat vs kitten: 0.996, nearly the same meaning. Cat vs car: −0.4367, unrelated (negative only because of the made-up vectors). Vector databases run this same calculation when they search.

Visualizing real embeddings

Only up to 3 dimensions can be plotted. To see 1,500-dimension embeddings, PCA (a dimensionality reduction technique) squeezes each vector to 2 dimensions; the words then form clusters like the plot above.

Takeaways

  • Dimensions = how many numbers per vector; set by the model, unnamed.
  • Similar words cluster when plotted.
  • Cosine similarity: close to 1 similar, 0 unrelated, −1 opposite.
