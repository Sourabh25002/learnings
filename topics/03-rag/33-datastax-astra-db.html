Section 5 · Lesson 33

DataStax Astra DB

From vector stores to full vector databases in the cloud (Lesson 22). Astra DB from DataStax is a fast database built on Apache Cassandra, with a free tier.

Setting it up

Create a Serverless (Vector) database ("optimized for vector and generative AI workloads"), name it, pick a cloud and region. Then collect two values: the API endpoint (on the database's page) and an application token (Account Settings → Tokens). Keep them in .env rather than in code. 

ASTRA_DB_API_ENDPOINT = "https://..."
ASTRA_DB_APPLICATION_TOKEN = "AstraCS:..."

Connecting

from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small",
    dimensions=1024,
    api_key="...",
)

The vectors are shortened to 1,024 numbers instead of 1,536 (how).

from langchain_astradb import AstraDBVectorStore

vector_store = AstraDBVectorStore(
    embedding=embeddings,
    api_endpoint=ASTRA_DB_API_ENDPOINT,
    collection_name="astra_vector_langchain",
    token=ASTRA_DB_APPLICATION_TOKEN,
    namespace=None,
)

This connects to the database and creates the collection astra_vector_langchain.

Adding and searching

vector_store.add_documents(documents=documents)

The same 10 posts as Lesson 32; the dashboard now shows 10 records.

vector_store.similarity_search("What is the weather?")
# weather forecast first, then other posts (e.g. the stock market one)

results = vector_store.similarity_search(
    "...",                      # a question about LangChain
    k=3,
    filter={"source": "tweet"},
)
for doc in results:
    print(doc.page_content, doc.metadata)
# "Building an exciting new project with LangChain ...", the LangGraph tweet, ...

With filter on metadata, only tweets are searched; the LangChain and LangGraph tweets come first.

results = vector_store.similarity_search_with_score("...", k=3)   # any question
for doc, score in results:
    print(f"[{score:.2f}] {doc.page_content}")
# scores around 0.72, 0.71, 0.53
Here, higher is better

Astra's scores (0.72, 0.71, 0.53) are similarities, unlike Chroma's and FAISS's distances (Lesson 24).

Retriever with a score threshold

retriever = vector_store.as_retriever(
    search_type="similarity_score_threshold",
    search_kwargs={"k": 1, "score_threshold": 0.5},
)
retriever.invoke("Stealing from the bank is a crime", filter={"source": "news"})
# the matching news post, with its metadata
search_typeBehaviour
"similarity"Top k (default)
"similarity_score_threshold"Top k, but only results scoring at least score_threshold, so weak matches are dropped instead of padding the context
"mmr"Covered in Section 7

In the dashboard's Data Explorer you can browse the records and filter them by metadata (e.g. the 3 news posts).

Takeaways

  • Astra DB: a serverless cloud vector database; connect with an endpoint and token.
  • Same LangChain methods as the local stores.
  • Its scores are similarities (higher = better); similarity_score_threshold drops weak matches.
