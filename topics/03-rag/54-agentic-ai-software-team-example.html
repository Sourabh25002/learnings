Section 10 · Lesson 54

Agentic AI Example: A Software Team

A workflow familiar from any IT company, turned into a team of AI agents: a concrete picture of how agentic AI replicates what people do.

From people to agents

A client's project in an Agile company goes through these roles; each can become an agent (an LLM with suitable prompting, since today's LLMs code well):

StageHuman roleAI agent
RequirementsBusiness analysts, product managersDrafts full requirements from a brief
Sprint planningProgram managerSplits the work into tasks
DevelopmentDevelopers 1, 2, 3Developer agents write the code for their tasks
TestingTesting teamRuns tests, raises bugs, sends feedback
Code review (in parallel)Lead or peer developersReviews the code and sends feedback

Multiple agents passing work and feedback to each other towards one goal: a working, tested solution.

Humans still in the loop

LLMs and agent systems aren't reliable enough to finish this alone yet, so people stay involved to check and correct. LangGraph supports this as human feedback in the loop, covered later.

Another example: blog generation

Separate agents for the title, the content and a thumbnail image, working together on one blog post. The course builds this later.

Takeaways

  • An agentic system can mirror a human team, one agent per role.
  • Humans stay in the loop for now.
