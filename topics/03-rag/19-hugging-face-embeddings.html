Section 4 · Lesson 19

Creating Embeddings with Hugging Face

Real text into real vectors, with a free, open-source model from Hugging Face, the main site for sharing AI models. (The next lesson does the same with OpenAI's paid models.)

The model

Hugging Face has models for every kind of task; searching for sentence-transformers (or "embedding models") lists embedding models. The course uses a small one, sentence-transformers/all-MiniLM-L6-v2:

From the model card

It maps sentences & paragraphs to a 384 dimensional dense vector space and can be used for tasks like clustering or semantic search.

Semantic search means searching by meaning, exactly what RAG does with these vectors.

Loading it

from langchain_huggingface import HuggingFaceEmbeddings

# Initialize a simple embedding model (no API key needed)
embeddings = HuggingFaceEmbeddings(
    model_name="sentence-transformers/all-MiniLM-L6-v2"
)
  • HuggingFaceEmbeddings loads any Hugging Face embedding model by its name, with no API key.
  • The first run downloads the model, so it's slow; later runs are fast.

A sentence transformer turns a whole sentence (or chunk) into one vector, not one vector per word. That fits RAG, whose data is sentences and chunks.

One text: embed_query

text = "Hello, I am learning about embeddings!"
embedding = embeddings.embed_query(text)

print(f"Text: {text}")
print(f"Embedding length: {len(embedding)}")   # 384
print(embedding)                                # [0.0123, -0.0456, ...] (384 numbers)

One string → one vector of 384 numbers, however long the sentence.

Many texts: embed_documents

sentences = [
    "The cat sat on the mat",
    "A feline rested on the rug",
    "The dog played in the yard",
    "I love programming in Python",
    "Python is my favorite programming language",
]

embedding_sentences = embeddings.embed_documents(sentences)

print(embedding_sentences[0])   # vector for "The cat sat on the mat"
print(embedding_sentences[1])   # vector for "A feline rested on the rug"

A list of strings → a list of vectors, in the same order. The same text always gives the same vector.

Choosing a model

Change model_name to switch. Popular sentence-transformers models:

ModelDimensionsStrengthUse when
all-MiniLM-L6-v2384Fast, good qualityGeneral purpose, real-time
all-mpnet-base-v2768Best quality, slowerQuality matters more than speed
all-MiniLM-L12-v2384A bit better than L6, a bit slowerBalance of speed and quality
A Q&A model (name not given)—Optimised for question answeringQ&A, semantic search
paraphrase-multilingual-MiniLM-L12-v238450+ languagesMultilingual text

More dimensions can capture finer shades of meaning, but take more storage and time; that's the quality/speed trade-off above.

Takeaways

  • HuggingFaceEmbeddings(model_name=...): any open model, free, no key.
  • embed_query = one text → one vector; embed_documents = list → list.
  • Pick the model for speed, quality or languages.
