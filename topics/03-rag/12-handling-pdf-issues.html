Section 3 · Lesson 12

Handling PDF Issues

Real PDFs are messy, and whatever mess you extract ends up in your chunks and answers. This lesson covers the common problems, a text cleaner, and a processor that cleans, chunks and enriches metadata in one go.

Common PDF problems

ProblemWhat it means
TablesRows and columns come out jumbled.
FormattingExtra spaces, line breaks and blank lines in odd places.
Scanned imagesPages that are pictures of text, with no text stored.
Extraction artifactsJunk left over from how the PDF was built.
Encoded charactersCharacters stored in unusual forms, like ligatures.

This lesson fixes whitespace and ligatures. Scanned pages need OCR or a multimodal model; images and tables come later.

Cleaning extracted text

raw_pdf_text = """Company Financial Report


    The financial   performance for fiscal year 2024
    shows significant growth in proﬁtability.

    Revenue increased by 25%.
"""
def clean_text(text):
    # 1. Collapse all whitespace to single spaces
    text = " ".join(text.split())

    # 2. Replace ligatures with normal letters
    text = text.replace("ﬁ", "fi")
    text = text.replace("ﬂ", "fl")
    return text
  • Whitespace: all runs of spaces, tabs and new lines collapse into single spaces.
  • Ligatures: many PDFs store "fi" and "fl" as one special character (ﬁ, ﬂ). It looks right, but proﬁtability won't match a search for "profitability". Replacing them with normal letters fixes that. 
Before: 'Company Financial Report\n\n\n    The financial   performance ... proﬁtability.'
After:  'Company Financial Report The financial performance ... profitability.'

Add more rules to the same function as your PDFs need.

A smart PDF processor

from typing import List
from langchain_core.documents import Document
from langchain_community.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter


class SmartPDFProcessor:
    """Advanced PDF processing with error handling"""

    def __init__(self, chunk_size=1000, chunk_overlap=100):
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap
        self.text_splitter = RecursiveCharacterTextSplitter(
            chunk_size=chunk_size,
            chunk_overlap=chunk_overlap,
            separators=[" "],
        )

    def process_pdf(self, pdf_path: str) -> List[Document]:
        """Process PDF with smart chunking and metadata enhancement"""
        # Load the PDF
        loader = PyPDFLoader(pdf_path)
        pages = loader.load()

        # Process each page
        processed_chunks = []
        for page_num, page in enumerate(pages):
            cleaned_text = self._clean_text(page.page_content)

            # Skip nearly empty pages
            if len(cleaned_text.strip()) < 50:
                continue

            # Split into chunks, adding extra metadata
            chunks = self.text_splitter.create_documents(
                texts=[cleaned_text],
                metadatas=[{
                    **page.metadata,
                    "page": page_num + 1,
                    "total_pages": len(pages),
                    "chunk_method": "smart_pdf_processor",
                    "char_count": len(cleaned_text),
                }],
            )
            processed_chunks.extend(chunks)

        return processed_chunks

    def _clean_text(self, text: str) -> str:
        text = " ".join(text.split())
        text = text.replace("ﬁ", "fi")
        text = text.replace("ﬂ", "fl")
        return text

The class keeps one splitter (1,000 characters, 100 overlap) and, for every page:

  1. CleanThe page text, with the function above.
  2. Skip empty pagesUnder 50 characters after cleaning: not enough to be useful.
  3. Chunk and enrich create_documents splits the text and makes a Document per chunk, giving each one the page's original metadata plus page, total_pages, chunk_method and char_count. 
processor = SmartPDFProcessor()

try:
    smart_chunks = processor.process_pdf("data/pdf/attention.pdf")
    print(f"Processed into {len(smart_chunks)} smart chunks")

    if smart_chunks:
        for key, value in smart_chunks[0].metadata.items():
            print(f"{key}: {value}")
except Exception as e:
    print(f"Processing error: {e}")

The 15-page paper becomes 49 chunks, each with the PDF's metadata plus the new keys.

Whenever you load from any source, clean the text and enrich the metadata: better chunks in the vector database mean better search and better answers.

Takeaways

  • PDF text needs cleaning: whitespace, ligatures and more.
  • Skip near-empty pages, then chunk and add useful metadata to every chunk.
