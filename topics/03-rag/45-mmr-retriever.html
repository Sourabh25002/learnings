Section 7 · Lesson 45

MMR Retriever in LangChain

The theory took a lesson; the code takes one argument.

from langchain_community.vectorstores import FAISS
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.chat_models import init_chat_model
from langchain_core.prompts import PromptTemplate
from langchain.chains.combine_documents import create_stuff_documents_chain
from langchain.chains import create_retrieval_chain
# Step 1: load and chunk the documents
loader = TextLoader("langchain_rag_dataset.txt")
raw_docs = loader.load()

splitter = RecursiveCharacterTextSplitter(chunk_size=300, chunk_overlap=50)
chunks = splitter.split_documents(raw_docs)
# Step 2: FAISS with Hugging Face embeddings
embedding_model = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
vectorstore = FAISS.from_documents(chunks, embedding_model)

The MMR retriever

# Step 3: MMR retriever
retriever = vectorstore.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 3},
)

search_type="mmr" is the only change; without it you get plain similarity search.

Tuning (not shown in the video)

fetch_k (default 20): how many similar candidates are fetched first; MMR picks k of them. lambda_mult (default 0.5): the λ from Lesson 44. E.g. search_kwargs={"k": 3, "fetch_k": 20, "lambda_mult": 0.7}.

In the RAG chain

prompt = PromptTemplate.from_template("""Answer the question based on the context provided.

Context:
{context}

Question: {input}""")

llm = init_chat_model("groq:gemma2-9b-it")

document_chain = create_stuff_documents_chain(llm=llm, prompt=prompt)
rag_chain = create_retrieval_chain(retriever=retriever, combine_docs_chain=document_chain)
query = "How does LangChain support agents and memory?"
response = rag_chain.invoke({"input": query})

print(response["answer"])
# "LangChain supports agents by letting LLMs act as decision makers ... It supports memory ..."

for doc in response["context"]:
    print("-", doc.page_content)     # the 3 chunks MMR selected

response["context"] shows the three chunks MMR chose: relevant, but covering different points instead of repeating one.

Takeaways

  • as_retriever(search_type="mmr", ...) makes any vector store an MMR retriever.
  • fetch_k and lambda_mult tune candidates and diversity.
