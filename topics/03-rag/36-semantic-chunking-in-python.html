Section 6 · Lesson 36

Semantic Chunking in Python

The algorithm from the previous lesson in plain Python, with a free Hugging Face model and a threshold of 0.7.

The sample text

LangChain is a framework for building applications with LLMs.
LangChain provides modular abstractions to combine LLMs with tools like OpenAI and Pinecone.
You can create chains, agents, memory, and retrievers.
The Eiffel Tower is located in Paris.
France is a popular tourist destination.

The first two sentences belong together; the third is about LangChain but never names it; the last two are about France.

from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

# Initialize the model
model = SentenceTransformer("all-MiniLM-L6-v2")

SentenceTransformer runs the same model as Lesson 19 directly, and scikit-learn's cosine_similarity replaces the hand-written one.

The code

text = """LangChain is a framework for building applications with LLMs.
LangChain provides modular abstractions to combine LLMs with tools like OpenAI and Pinecone.
You can create chains, agents, memory, and retrievers.
The Eiffel Tower is located in Paris.
France is a popular tourist destination."""

# Step 1: split into sentences
sentences = [s.strip() for s in text.split("\n") if s.strip()]

# Step 2: embed each sentence
embeddings = model.encode(sentences)

# Step 3: initialize parameters
threshold = 0.7                      # controls chunk tightness
chunks = []
current_chunk = [sentences[0]]       # start with the first sentence

# Step 4: semantic grouping based on the threshold
for i in range(1, len(sentences)):
    sim = cosine_similarity([embeddings[i - 1]], [embeddings[i]])[0][0]
    if sim >= threshold:
        current_chunk.append(sentences[i])        # similar: same chunk
    else:
        chunks.append(" ".join(current_chunk))    # not similar: close the chunk
        current_chunk = [sentences[i]]            # and start a new one

chunks.append(" ".join(current_chunk))            # don't forget the last chunk

for idx, chunk in enumerate(chunks):
    print(f"Chunk {idx + 1}: {chunk}")
  1. SplitOne sentence per line (full stops would work too).
  2. Embedmodel.encode gives one vector per sentence.
  3. GroupCompare each sentence with the previous one: at or above 0.7, add it to the current chunk; below, close the chunk and start a new one. Don't forget the last chunk.

The result

ChunkTextWhy
1LangChain is a framework for building applications with LLMs. LangChain provides modular abstractions to combine LLMs with tools like OpenAI and Pinecone.Both about LangChain: merged.
2You can create chains, agents, memory, and retrievers.Never says "LangChain", so not similar enough.
3The Eiffel Tower is located in Paris.New topic.
4France is a popular tourist destination.Doesn't mention Paris.

Chunk 2 shows the method's weak spot: a sentence that depends on its neighbour for meaning can be split off. A lower threshold merges more readily, a higher one splits more; try different values on your data.

Takeaways

  • Split → embed → compare each sentence with the previous → group by threshold.
  • The threshold (0.7 here) controls how tight the chunks are.
