Section 11 · Lesson 61

Structured Output with Dataclasses and Agents

Agents can return structured output too: create_agent(..., response_format=Schema) puts the result in result["structured_response"]. The same contact extraction with all three schema types:

Pydantic

from pydantic import BaseModel
from langchain.agents import create_agent

class ContactInfo(BaseModel):
    name: str
    email: str
    phone: str

agent = create_agent(
    model="gpt-5",
    tools=[],
    response_format=ContactInfo,
)

result = agent.invoke({
    "messages": [{
        "role": "user",
        "content": "Extract contact info from: John Doe, john@example.com, (555) 123-4567",
    }]
})

result["structured_response"]
# ContactInfo(name='John Doe', email='john@example.com', phone='(555) 123-4567')

→ ContactInfo(name='John Doe', email='john@example.com', phone='(555) 123-4567'), validated.

TypedDict

from typing_extensions import TypedDict

class ContactInfo(TypedDict):
    name: str
    email: str
    phone: str

agent = create_agent(model="gpt-5", response_format=ContactInfo)
result = agent.invoke({"messages": [{"role": "user", "content": "Extract contact info from: ..."}]})

result["structured_response"]
# {'name': 'John Doe', 'email': 'john@example.com', 'phone': '(555) 123-4567'}

→ a plain dictionary, no validation.

Dataclass

from dataclasses import dataclass
from langchain.agents import create_agent

@dataclass
class ContactInfo:
    """Contact information for a person."""
    name: str      # the name of the person
    email: str     # the email address
    phone: str     # the phone number

agent = create_agent(model="gpt-5", response_format=ContactInfo)
result = agent.invoke({"messages": [{"role": "user", "content": "Extract contact info from: ..."}]})

result["structured_response"]
# ContactInfo(name='John Doe', email='john@example.com', phone='(555) 123-4567')

A @dataclass (Python 3.7+) is a class that just holds data; no validation. → a ContactInfo object.

Comparison

PydanticTypedDictDataclass
ValidationYesNoNo
DescriptionsField(description=)Annotated[...]Docstring / comments
ResultModel objectDictDataclass object

On a model: with_structured_output(Schema). On an agent: response_format=Schema.

Use Pydantic when the data must be checked; TypedDict or a dataclass when you just need the shape.
