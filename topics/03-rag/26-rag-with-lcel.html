Section 5 · Lesson 26

Building the RAG Chain with LCEL

The same RAG chain as Lesson 25, built without helper functions, using LCEL (LangChain Expression Language): you connect each step yourself with the | (pipe) symbol, which passes one step's output into the next.

New pieces

from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough, RunnableParallel
PieceRole
StrOutputParserTurns the LLM's reply into a plain string.
RunnablePassthroughPasses its input on unchanged, e.g. the user's question.
RunnableParallelRuns several steps side by side.

How these runnables fit together is on the background page.

The prompt

custom_prompt = ChatPromptTemplate.from_template("""Use the following context to answer the question.
If you don't know the answer based on the context, say you don't know.
Provide specific details from the context to support your answer.

Context:
{context}

Question: {question}

Answer:""")

Two placeholders: context (the chunks) and question.

Formatting the chunks

def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)

The retriever returns a list of Documents; this joins their text into one block, separated by blank lines. It's what create_stuff_documents_chain did for us.

The chain

rag_chain_lcel = (
    {
        "context": retriever | format_docs,
        "question": RunnablePassthrough(),
    }
    | custom_prompt
    | llm
    | StrOutputParser()
)
  1. Build the inputs"context": the question goes to the retriever, and its chunks through format_docs. "question": the question passed straight through. The keys match the prompt's placeholders.
  2. PromptFills in both placeholders.
  3. LLMWrites the answer.
  4. ParserReturns it as a string.
Brackets

| StrOutputParser without () fails with "takes 1 positional argument but 2 were given".

Running it

response = rag_chain_lcel.invoke("What is deep learning?")
print(response)
# "Deep learning is a subset of machine learning based on artificial neural networks.
#  This network consists of layers of interconnected ..."

The input is a plain string: it flows into both the retriever and the question slot. The output is only the answer; to see the chunks it used, ask the retriever:

docs = retriever.get_relevant_documents("What is deep learning?")
for doc in docs:
    print(doc.metadata["source"], doc.page_content[:100])   # chunks from doc_1.txt, doc_0.txt, ...

(Newer LangChain versions prefer retriever.invoke(question).) A helper showing both:

def query_rag_lcel(question):
    print(f"Question: {question}")
    # With RunnablePassthrough, pass the string directly
    answer = rag_chain_lcel.invoke(question)
    print(f"Answer: {answer}")

    docs = retriever.get_relevant_documents(question)
    print("Source documents:")
    for doc in docs:
        print("-", doc.page_content[:100])

query_rag_lcel("What are the key concepts in reinforcement learning?")
# Answer: "The key concepts in reinforcement learning are interaction with an environment ..."

Built-in vs LCEL

Combine chunkscreate_stuff_documents_chainretriever | format_docs
Add retrievalcreate_retrieval_chainThe {"context": ..., "question": ...} step
Call with.invoke({"input": "..."}).invoke("...")
ReturnsDict: input, context, answerThe answer string

Takeaways

  • LCEL pipes steps together with |: inputs → prompt → LLM → parser.
  • The first step is a dictionary whose keys match the prompt's placeholders.
  • You control every step, e.g. how chunks are formatted.
