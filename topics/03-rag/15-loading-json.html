Section 3 · Lesson 15

Loading JSON

Data from APIs usually arrives as JSON: nested text made of keys, values and lists. The main question is which part becomes a Document.

The sample, company_data.json, is nested:

{
  "company": "TechCorp",
  "employees": [
    {
      "id": 1,
      "name": "...",
      "role": "...",
      "skills": ["...", "..."],
      "projects": [
        {"name": "RAG System", "status": "In Progress"}
      ]
    },
    {
      "id": 2,
      ...
    }
  ],
  "departments": { ... }
}

A second file holds website events (timestamp, event, user_id, page), used in the assignment.

Method 1: JSONLoader

from langchain_community.document_loaders import JSONLoader

employee_loader = JSONLoader(
    file_path="data/json_files/company_data.json",
    jq_schema=".employees[]",   # one Document per employee
    text_content=False,          # keep the full JSON object
)
employee_docs = employee_loader.load()
print(f"Loaded {len(employee_docs)} employee documents")   # 2
ParameterMeaning
jq_schemaA jq query picking which part to load. .employees[] = "go to employees and take each item", so every employee becomes a Document. Needs the jq package.
text_contentFalse keeps the full JSON object for each item.

2 Documents, one per employee. page_content is the employee's raw JSON; metadata has source and seq_num.

Method 2: custom processing

import json
from typing import List
from langchain_core.documents import Document


def process_json_intelligently(filepath: str) -> List[Document]:
    with open(filepath, "r") as f:
        data = json.load(f)

    documents = []
    for emp in data.get("employees", []):
        content = (
            f"Employee Profile:\n"
            f"Name: {emp['name']}\n"
            f"Role: {emp['role']}\n"
            f"Skills: {', '.join(emp['skills'])}\n\n"
            f"Projects:"
        )
        for proj in emp.get("projects", []):
            content += f"\n- {proj['name']} (Status: {proj['status']})"

        documents.append(Document(
            page_content=content,
            metadata={
                "source": filepath,
                "data_type": "employee_profile",
                "employee_id": emp["id"],
                "employee_name": emp["name"],
                "role": emp["role"],
            },
        ))
    return documents

docs = process_json_intelligently("data/json_files/company_data.json")

Each employee, including the nested projects, becomes readable text, with the metadata you choose.

Which to use

JSONLoader + jq_schemaCustom
EffortA few linesYour own function
page_contentRaw JSON (braces, quotes…)Readable text you design
metadatasource, seq_numAny fields you choose

Rule of thumb: load it and look at the Documents. If they aren't the shape you need, convert them yourself and add useful metadata.

Assignment

Load the events file and put its fields (timestamp, event, user_id…) into each Document's metadata.

Takeaways

  • JSONLoader + jq_schema picks which records become Documents.
  • Custom code gives readable text and chosen metadata.
