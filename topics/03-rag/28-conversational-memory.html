Section 5 · Lesson 28

Conversational Memory

Ask "What is machine learning?", then "What are its types?" The second question is embedded and searched on its own; nothing in it says "machine learning", so retrieval fails. Conversational memory brings the previous conversation in.

The pieces

from langchain.chains import create_history_aware_retriever
from langchain_core.prompts import MessagesPlaceholder
from langchain_core.messages import HumanMessage, AIMessage
  • create_history_aware_retriever: makes the retriever use the conversation.
  • MessagesPlaceholder: a slot in a prompt where the chat history goes.
  • HumanMessage / AIMessage: the user's and the LLM's messages in that history.

1. Rewrite the question before searching

contextualize_q_system_prompt = """Given a chat history and the latest user question
which might reference context in the chat history, formulate a standalone question
which can be understood without the chat history. Do NOT answer the question,
just reformulate it if needed and otherwise return it as is."""

contextualize_q_prompt = ChatPromptTemplate.from_messages([
    ("system", contextualize_q_system_prompt),
    MessagesPlaceholder("chat_history"),     # the previous conversation goes here
    ("human", "{input}"),                    # the latest question
])

The LLM turns the latest question into a standalone question (one that makes sense without the history): "What are its types?" → something like "What are the types of machine learning?" It must not answer, only rewrite. 

history_aware_retriever = create_history_aware_retriever(
    llm,
    retriever,
    contextualize_q_prompt,
)

The rewritten question is what gets searched.

2. The answering chain, with history

qa_system_prompt = """You are an assistant for question-answering tasks.
Use the following pieces of retrieved context to answer the question.
If you don't know the answer, just say that you don't know.
Use three sentences maximum and keep the answer concise.

{context}"""

qa_prompt = ChatPromptTemplate.from_messages([
    ("system", qa_system_prompt),
    MessagesPlaceholder("chat_history"),
    ("human", "{input}"),
])

question_answer_chain = create_stuff_documents_chain(llm, qa_prompt)

The usual stuff-documents chain, with the history also in its prompt.

3. Put them together

conversational_rag_chain = create_retrieval_chain(
    history_aware_retriever,      # instead of the plain retriever
    question_answer_chain,
)

The only change from Lesson 25: the history-aware retriever replaces the plain one.

Using it

chat_history = []     # starts empty

# First question
result1 = conversational_rag_chain.invoke({
    "chat_history": chat_history,
    "input": "What is machine learning?",
})
print(result1["answer"])
# "Machine learning is a subset of artificial intelligence ..."

# Add this exchange to the history
chat_history.extend([
    HumanMessage(content="What is machine learning?"),
    AIMessage(content=result1["answer"]),
])

# Follow-up question: "its" = machine learning
result2 = conversational_rag_chain.invoke({
    "chat_history": chat_history,
    "input": "What are its main types?",
})
print(result2["answer"])
# "The main types of machine learning are supervised learning, ..."

The follow-up "What are its main types?" is answered about machine learning, because the chain sees the earlier exchange.

The chain doesn't remember by itself

"Memory" is the chat_history list you keep: after every turn, append the question (HumanMessage) and answer (AIMessage) and pass the list on every call.

Takeaways

  • Follow-ups fail in plain RAG because each question is searched alone.
  • History-aware retriever: an LLM rewrites the question into a standalone one, then it's searched.
  • The history goes into both the rewrite prompt and the answer prompt; you maintain it.
