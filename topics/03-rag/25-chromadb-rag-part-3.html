Section 5 · Lesson 25

RAG with ChromaDB, Part 3: The LLM and the Retrieval Chain

Part 2 found the right chunks. Now the last two steps of RAG: put those chunks into a prompt (augmentation) and let an LLM write the answer (generation). LangChain has two ready-made helpers that wire this up.

1. Load the LLM

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-3.5-turbo",
    temperature=0.2,
    max_tokens=500,
)

test_response = llm.invoke("What is LLM?")
print(test_response)
  • temperature: how random the answer is (0 = focused, 1 = creative). max_tokens: the longest answer allowed. Both are optional (more).
  • invoke sends a question and returns the model's reply (an AIMessage). The old predict is deprecated.

Asked "What is LLM?" with no context, the model answered "Master of Laws", the law degree. Without context it simply guesses.

Or: init_chat_model

from langchain.chat_models import init_chat_model

llm = init_chat_model("openai:gpt-3.5-turbo")
# llm = init_chat_model("groq:<model-name>")    # a Groq model instead

llm.invoke("What is AI?")

Give it "provider:model" and it creates the right model class, so switching to Groq or Gemini is a one-word change.

2. Turn the vector store into a retriever

retriever = vectorstore.as_retriever(
    search_kwargs={"k": 3}     # retrieve the top 3 relevant chunks
)

A retriever is a small wrapper around the vector store whose only job is to fetch the top-k matching chunks for a question. Chains accept retrievers, not raw vector stores, so this step is always needed.

3. Write the prompt

from langchain_core.prompts import ChatPromptTemplate

system_prompt = """You are an assistant for question-answering tasks.
Use the following pieces of retrieved context to answer the question.
If you don't know the answer, just say that you don't know.
Use three sentences maximum and keep the answer concise.

{context}"""

prompt = ChatPromptTemplate.from_messages([
    ("system", system_prompt),
    ("human", "{input}"),
])

The system prompt is the instruction to the LLM. {context} gets filled with the retrieved chunks and {input} with the user's question.

4. The document chain

from langchain.chains.combine_documents import create_stuff_documents_chain

document_chain = create_stuff_documents_chain(llm, prompt)

"Stuff" means putting all the retrieved chunks into {context} at once. This chain fills the prompt, sends it to the LLM and returns the answer as text. (Joining steps into a chain like this is called LCEL, next lesson.)

5. The retrieval chain

from langchain.chains import create_retrieval_chain

rag_chain = create_retrieval_chain(retriever, document_chain)

Adds the retriever in front: question → retriever finds chunks → document chain answers.

Run it

response = rag_chain.invoke({"input": "What is deep learning?"})

print(response["answer"])
KeyContains
inputThe question
contextThe 3 chunks that were stuffed into the prompt
answer"Deep learning is a subset of machine learning that relies on artificial neural networks inspired by the human brain…"

The key is "input" because that's the placeholder's name. To ask several questions:

def query_rag(question):
    result = rag_chain.invoke({"input": question})
    print(f"Question: {question}")
    print(f"Answer: {result['answer']}")
    print("Retrieved context:")
    for doc in result["context"]:
        print("-", doc.page_content[:100])

test_questions = [
    "What are the three types of machine learning?",
    "What is deep learning?",
    "What are CNNs best used for?",
]
for q in test_questions:
    query_rag(q)

Answers: supervised (and other) types of ML; deep learning as a subset of ML; CNNs for image processing. The full pipeline (load → split → embed → store → search → prompt → LLM) is now complete.

Takeaways

  • LLM: ChatOpenAI(...) or init_chat_model("provider:model").
  • Vector store → retriever with as_retriever(search_kwargs={"k": 3}).
  • Prompt: {context} for chunks, {input} for the question.
  • create_stuff_documents_chain fills the prompt and calls the LLM; create_retrieval_chain puts the retriever in front.
