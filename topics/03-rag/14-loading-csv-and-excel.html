Section 3 · Lesson 14

Loading CSV and Excel

Text, PDF and Word are unstructured data (free-flowing text). CSV and Excel are structured: rows and columns (more). They can be loaded with LangChain loaders or with your own pandas code, which gives better metadata.

The samples: products.csv (5 products: Product, Category, Price, Description) and inventory.xlsx (sheets Products and Summary).

CSV method 1: CSVLoader

from langchain_community.document_loaders import CSVLoader

csv_loader = CSVLoader(
    file_path="data/structured_files/products.csv",
    encoding="utf-8",
    csv_args={
        "delimiter": ",",    # what separates values (a comma in a CSV)
        "quotechar": '"',    # what wraps a value that itself contains a comma
    },
)
csv_docs = csv_loader.load()
print(len(csv_docs))   # 5

CSVLoader turns every row into its own Document.

5 rows → 5 Documents. page_content holds the row's columns and values; metadata gets source and row.

CSV method 2: custom processing

import pandas as pd
from typing import List
from langchain_core.documents import Document


def process_csv_intelligently(filepath: str) -> List[Document]:
    """Custom CSV processing for better control"""
    df = pd.read_csv(filepath)
    documents = []

    # Strategy: one document per row, with structured content
    for idx, row in df.iterrows():
        content = (
            f"Product: {row['Product']}\n"
            f"Category: {row['Category']}\n"
            f"Price: ${row['Price']}\n"
            f"Description: {row['Description']}"
        )
        doc = Document(
            page_content=content,
            metadata={
                "source": filepath,
                "row_index": idx,
                "product": row["Product"],
                "category": row["Category"],
                "price": row["Price"],
                "data_type": "product_info",
            },
        )
        documents.append(doc)

    return documents   # outside the loop!

Each row becomes readable "Column: value" text, and its product, category and price become separate metadata fields. These can later filter searches (e.g. one category only). You can add any extra context too, such as how this file relates to others.

Excel

Method 1: pandas

def process_excel_with_pandas(filepath: str) -> List[Document]:
    documents = []
    excel_file = pd.ExcelFile(filepath)

    for sheet_name in excel_file.sheet_names:
        df = pd.read_excel(filepath, sheet_name=sheet_name)

        sheet_content = f"Sheet: {sheet_name}\n"
        sheet_content += f"Columns: {', '.join(df.columns)}\n\n"
        sheet_content += df.to_string(index=False)

        documents.append(Document(
            page_content=sheet_content,
            metadata={
                "source": filepath,
                "sheet_name": sheet_name,
                "num_rows": len(df),
                "num_columns": len(df.columns),
                "data_type": "excel_sheet",
            },
        ))

    return documents

excel_docs = process_excel_with_pandas("data/structured_files/inventory.xlsx")
print(len(excel_docs))   # 2: one per sheet

One Document per sheet, with the sheet name in metadata: 2 Documents for the inventory file.

Method 2: UnstructuredExcelLoader

from langchain_community.document_loaders import UnstructuredExcelLoader

excel_loader = UnstructuredExcelLoader("data/structured_files/inventory.xlsx")
excel_docs = excel_loader.load()

Handles complex Excel features and keeps formatting information, but needs unstructured and is slow.

The pattern

Built-in loaders give Documents automatically. Your own code means you decide exactly what goes into page_content and metadata. Either way, Documents move on to chunking, embedding and storage.

Takeaways

  • CSVLoader: one Document per row, zero effort.
  • Custom code: column values as metadata, for filtering and better answers.
  • Excel: one Document per sheet with pandas, or UnstructuredExcelLoader.
