Middleware and Summarization

Middleware runs your own steps at fixed points inside an agent: for logging, prompt changes, retries and fallbacks, limits, guardrails or PII detection.

An airport: security, immigration and boarding are checks at fixed points between the entrance and the gate. Each can inspect, change or stop what passes. Middleware works the same way.

Hooks

Middleware attaches to hooks in the agent loop: before/after the agent, before/after the model, and around tool calls.

Built-in middlewareDoes
SummarizationSummarizes old history as it nears token limits
Human-in-the-loopPauses for human approval of tool calls (next lesson)
Model / tool call limitsCap calls to control cost and loops
Model fallbackSwitches model if one fails

SummarizationMiddleware

Long conversations keep growing until they hit the context window. This middleware has an LLM summarise the older messages and keeps the recent ones, essential for long chatbot sessions, including conversational RAG. 

from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware
from langgraph.checkpoint.memory import InMemorySaver
from langchain_core.messages import HumanMessage

agent = create_agent(
    model="gpt-4o-mini",
    tools=[],
    checkpointer=InMemorySaver(),
    middleware=[
        SummarizationMiddleware(
            model="gpt-4o-mini",
            trigger=("messages", 10),     # summarize when there are 10 messages
            keep=("messages", 4),         # keep the 4 most recent as they are
        ),
    ],
)

trigger says when to summarise (here at 10 messages), keep how much to leave untouched (4 messages). Use a cheap model for summarising, since it runs repeatedly. The checkpointer keeps the conversation between calls. 

config = {"configurable": {"thread_id": "test-1"}}     # one conversation / user

questions = ["What is 2+2?", "What is 10*5?", "What is 100/4?", "What is 15-7?", ...]
for q in questions:
    response = agent.invoke({"messages": [HumanMessage(q)]}, config)
    print(response["messages"][-1].content)
    print(len(response["messages"]))

The message count goes 2, 4, 6, 8, 10, then drops to 6, starting with "Here is a summary of the conversation to date…".

Other triggers

from langchain.tools import tool

@tool
def search_hotels(city: str) -> str:
    """Search for hotels in a city."""
    return f"Hotels in {city}: Grand Hotel, ..."      # stands in for a real API

agent = create_agent(
    model="gpt-4o-mini",
    tools=[search_hotels],
    checkpointer=InMemorySaver(),
    middleware=[
        SummarizationMiddleware(
            model="gpt-4o-mini",
            trigger=("tokens", 550),      # summarize above 550 tokens
            keep=("tokens", 200),         # keep the most recent ~200 tokens
        ),
    ],
)

def count_tokens(messages):
    total_chars = sum(len(str(m.content)) for m in messages)
    return total_chars // 4               # rough rule: ~4 characters per token

for city in ["Paris", "London", "Tokyo", "New York", "Dubai", "Singapore"]:
    response = agent.invoke({"messages": [HumanMessage(f"Find hotels in {city}")]}, config)
    print(len(response["messages"]), count_tokens(response["messages"]))

Counted in tokens (above 550, keep ~200): the estimate climbs 149 → 302 → 456, then falls to 396 and 232 as summaries replace old messages.

SummarizationMiddleware(
    model="gpt-4o-mini",
    trigger=("fraction", 0.005),          # 0.5% of the model's context window
    keep=("fraction", 0.002),             # keep 0.2%
)

Or a fraction of the context window: 0.5% of gpt-4o-mini's ~128K tokens ≈ 640 tokens, which adapts to any model. (The video says 160K; 640 is 0.5% of 128K.)

Takeaways

  • Middleware = your steps at hooks inside the agent.
  • SummarizationMiddleware(model, trigger, keep) by messages, tokens or fraction.
