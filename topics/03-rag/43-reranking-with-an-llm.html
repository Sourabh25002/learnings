Section 7 · Lesson 43

Reranking with an LLM

An LLM reranker by hand: retrieve chunks, ask an LLM to rank them, reorder.

Data and retriever

from langchain_community.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.chat_models import init_chat_model
from langchain_core.prompts import PromptTemplate
from langchain_core.documents import Document
from langchain_core.output_parsers import StrOutputParser

loader = TextLoader("langchain_sample.txt")
raw_docs = loader.load()

splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
docs = splitter.split_documents(raw_docs)

query = "How can I use LangChain to build an application with memory and tools?"
from langchain_community.vectorstores import FAISS
from langchain_huggingface import HuggingFaceEmbeddings

embedding_model = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
vectorstore = FAISS.from_documents(docs, embedding_model)
retriever = vectorstore.as_retriever(search_kwargs={"k": 8})

A dense FAISS retriever (a hybrid one from Lesson 40 works too). Local Hugging Face embeddings took ~1.5 minutes on this large file; OpenAI's API took ~2.6 seconds:

# Alternative: OpenAI embeddings
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings()
vectorstore_openai = FAISS.from_documents(docs, embeddings)
retriever_openai = vectorstore_openai.as_retriever(search_kwargs={"k": 8})

The ranking prompt

import os

os.environ["GROQ_API_KEY"] = os.getenv("GROQ_API_KEY")
llm = init_chat_model("groq:gemma2-9b-it")

prompt = PromptTemplate.from_template("""You are a helpful assistant. Your task is to rank the
following documents from most to least relevant to the user's question.

User Question: "{question}"

Documents:
{documents}

Instructions:
- Think about the relevance of each document to the user's question.
- Return a list of document indices in ranked order, starting from the most relevant.

Output format: comma-separated document indices (e.g., 2,1,3,0,...)""")

The whole reranker: the question plus numbered documents in, a comma-separated list of document numbers out. A strict output format makes the answer easy to read in code.

Ranking and reordering

# 1. Retrieve the top-k chunks
retrieved_docs = retriever.invoke(query)

# 2. Number them so the LLM can refer to them
doc_lines = [f"{i + 1}. {doc.page_content}" for i, doc in enumerate(retrieved_docs)]
formatted_docs = "\n".join(doc_lines)
# 1. LangChain is ...
# 2. ...

# 3. Ask the LLM for the ranking
chain = prompt | llm | StrOutputParser()
response = chain.invoke({"question": query, "documents": formatted_docs})
print(response)    # "2,1,4,5,6"

The LLM answered 2,1,4,5,6: document 2 is most relevant, then 1, and so on.

# Turn "2,1,4,5,6" into Python list positions
indices = [int(x.strip()) - 1 for x in response.split(",") if x.strip().isdigit()]
print(indices)     # [1, 0, 3, 4, 5]

# Reorder the documents
reranked_docs = [retrieved_docs[i] for i in indices if 0 <= i < len(retrieved_docs)]

for i, doc in enumerate(reranked_docs, 1):
    print(f"Rank {i}: {doc.page_content}")
# Rank 1: LangChain is a flexible framework designed for developing applications ...
# Rank 2: LangChain supports tool integration ...

The numbers are converted to list positions (the prompt counts from 1) and the documents reordered.

LLM output isn't guaranteed

Document 3 is missing from 2,1,4,5,6: the LLM just left it out. It could also repeat or invent numbers, so the code keeps only valid ones. Treat LLM output as untrusted text.

The reranked documents then become the context for the final answer (e.g. the chain from Lesson 26).

Takeaways

  • An LLM reranker is a prompt returning document order in a strict format.
  • Parse defensively, then generate from the reordered documents.
