Section 3 · Lesson 13

Loading Word Documents

Two loaders for .docx files with very different results: Docx2txtLoader gives the whole file as one Document; UnstructuredWordDocumentLoader splits it into its structural pieces.

The sample, data/word_files/proposal.docx, is a project proposal with sections (executive summary, key objectives…) and tables. Packages: python-docx and docx2txt for method 1, unstructured for method 2. 

from langchain_community.document_loaders import (
    Docx2txtLoader,
    UnstructuredWordDocumentLoader,
)

Method 1: Docx2txtLoader

try:
    docx_loader = Docx2txtLoader("data/word_files/proposal.docx")
    docs = docx_loader.load()

    print(f"Loaded {len(docs)} document(s)")
    print(f"Content preview: {docs[0].page_content[:100]}...")
    print(f"Metadata: {docs[0].metadata}")
except Exception as e:
    print(f"Error: {e}")

1 Document with all the text, like a text file. You'd chunk it with a splitter next.

Method 2: UnstructuredWordDocumentLoader

try:
    unstructured_loader = UnstructuredWordDocumentLoader(
        "data/word_files/proposal.docx",
        mode="elements",
    )
    unstructured_docs = unstructured_loader.load()

    print(f"Loaded {len(unstructured_docs)} elements")
    for i, doc in enumerate(unstructured_docs[:3]):
        print(f"\nElement {i + 1}:")
        print(f"  Type: {doc.metadata.get('category', 'unknown')}")
        print(f"  Content: {doc.page_content[:100]}...")
except Exception as e:
    print(f"Error: {e}")
Loaded 20 elements

Element 1:
  Type: Title
  Content: Project Proposal: RAG Implementation...

Element 2:
  Type: Title
  Content: Executive Summary...

Element 3:
  Type: NarrativeText
  Content: ...

mode="elements" follows the document's layout and returns each element (a title, a paragraph, a table) as its own Document.

  • metadata["category"] says what each element is: Title, NarrativeText, …
  • Tables come out as their own elements.
  • Rich metadata, including parent_id, which links an element to the one it belongs under (a paragraph to its section title).
  • Already chunk-sized; split further only if an element is too big.
  • Slow: about 35 seconds on this small file.

Which to use

Docx2txtLoaderUnstructured (elements)
Returns1 Document per file1 Document per element (20 here)
StructureLost: plain textKept: titles, paragraphs, tables labelled
TablesFlattened into the textSeparate elements
SpeedFastSlow
ChunkingNeeded nextMostly done

Takeaways

  • Docx2txtLoader: fast, one plain-text Document.
  • Unstructured, elements mode: slow, but keeps structure and tables, with natural chunks.
