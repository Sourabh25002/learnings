Section 5 · Lesson 29

Using Groq LLMs

OpenAI's LLMs cost money. Groq gives free API access (a number of free requests) to many open models, which is handy for practice. Swapping the LLM leaves the rest of the pipeline untouched.

API key

Create a key at console.groq.com, add it to .env as GROQ_API_KEY, and load it like the OpenAI key (Lesson 20):

import os
from dotenv import load_dotenv

load_dotenv()
os.getenv("GROQ_API_KEY")       # check it's loaded

os.environ["GROQ_API_KEY"] = os.getenv("GROQ_API_KEY")

Creating the model

The course uses gemma2-9b-it, an open model from Google (what the name means). Groq's list changes, so pick another from the console if it's gone. Two equivalent ways: 

from langchain_groq import ChatGroq

llm = ChatGroq(model="gemma2-9b-it")
# or pass the key directly: ChatGroq(model="gemma2-9b-it", api_key="...")
from langchain.chat_models import init_chat_model

llm = init_chat_model("groq:gemma2-9b-it")

ChatGroq directly, or init_chat_model with "provider:model" (Lesson 25). With GROQ_API_KEY set, no key is needed in the call.

Using it

Pass the Groq llm wherever a chain used the OpenAI one. That completes the traditional RAG pattern on Chroma, from ingestion to answer. It underlies every later type of RAG.

Takeaways

  • Groq: free access to open models.
  • ChatGroq(model=...) or init_chat_model("groq:...").
  • Swapping the LLM doesn't change the chain.
